📊 Sales & Customer Analytics Dashboard (Power BI)

An interactive Power BI dashboard designed for the Retail & Furniture domain, providing actionable insights into sales performance, customer behavior, and profitability.

🔹 Project Overview

This project demonstrates how data visualization can transform raw sales and customer data into business-ready insights. The dashboard covers:

Net Sales & Profit Trends

Target Achievement & Discount Impact

Customer Segmentation with RFM Scoring

Top Customers & Salesperson Performance

Regional & Category-wise Analysis

🔹 Key Features

✅ Sales Performance – Track net sales ($2.12M), profit ($286K), and margin % over time
✅ Target Analysis – Identify met vs. unmet targets at state and segment level
✅ Customer Segmentation – High/Medium/Low value tiers using RFM (Recency, Frequency, Monetary) analysis
✅ Discount Analysis – See how discounts influence profitability across segments
✅ Top Contributors – Highlight top customers and salespersons driving business

🔹 Tools & Skills Used

Power BI (Data Modeling, DAX, Visualizations)

Excel / CSV Data (for source & transformations)

RFM Analysis (Customer Value Classification)

Data Storytelling (Turning KPIs into insights)
